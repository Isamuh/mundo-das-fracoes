# Mundo das Frações

Jogo educacional de frações em desenvolvimento com TypeScript, Phaser 3 e Vite.

## Como usar

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
3. Rode os testes:
   ```bash
   npm test
   ```

## Estrutura do projeto

- `src/` - código-fonte do jogo
- `math/` - lógica de frações e validação matemática
- `tests/` - testes automatizados
- `public/` - ativos públicos

## Observações

Este repositório ainda está em fase inicial. O foco atual é o primeiro vertical slice do projeto, com um nível funcional e a lógica de frações testável separada da renderização.
